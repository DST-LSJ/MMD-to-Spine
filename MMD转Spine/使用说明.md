# MMD → Spine 通用骨架转换工具

运行环境：Python 3.10及以上（验证环境Python 3.14），输出供Spine 4.3导入。只使用Python标准库，无需第三方库。压缩包不包含Python或Spine软件。

## 使用main.py

1. 完整解压到可写文件夹，将人物动作VMD放到main.py旁边。
2. 在该文件夹运行 `python main.py`，或用Python编辑器打开main.py运行。安装了Windows Python启动器也可使用 `py main.py`。
3. 导入同目录生成的 `<动作名>_通用骨架_<起点>秒起_<时长>秒_spine.json`。保留Texture2D文件夹，Spine导入时使用完整JSON。

导出的图片路径为相对路径 `Texture2D/`，指向JSON所在文件夹下的Texture2D。移动或分享输出时将JSON与Texture2D一起移动；使用--output-dir或-o输出到其他目录时，也需要在该目录放置Texture2D。不再写入开发电脑的绝对路径。

转换时显示文件序号、百分比进度条和当前阶段（三维骨架、二维动作、附加效果、写入校验）。完成后在交互控制台提示“按任意键退出，或10秒后自动退出”。无VMD、全部跳过或失败时也会保留结果提示。--no-wait可立即退出；输出重定向或自动化运行不等待，--help也不等待。

唯一入口是main.py，没有BAT。命令行直接运行时扫描当前工作文件夹；使用编辑器时请把工作目录设为软件目录，或通过--folder明确指定输入目录。

文件名不限，支持扩展名.vmd/.VMD，不扫描子目录。相机、灯光、道具、纯表情等无可识别人物肢体轨道的文件会提示忽略；损坏文件单独报错，其余文件继续处理。“任意VMD”不等于自动识别所有自定义骨架，仍需标准人物骨名或配置中的别名。

## 时间与选项

main.py顶部可调整：

```python
START_SECONDS = 0
DURATION_SECONDS = 300.0
ENABLE_SECONDARY_MOTION = True
ENABLE_BLINK = True
```

默认从0秒开始，最多300秒；超过源末尾自动截断，输出从0秒计时。更长动作可调大持续时长。

```text
python main.py
python main.py --folder "D:\动作" --start 10 --duration 20
python main.py "我的动作.vmd" --duration 600
python main.py --force
```

--output-dir指定输出目录；--no-secondary关闭发裙摆动；--no-blink关闭眨眼；--no-debug关闭详细报告。报告位于文档/诊断_v2。

## 不重复生成

成功转换后生成.mmd_spine_cache.json。再次运行时，输入、参数、运行资源和输出内容均不变则跳过；输出被修改/删除、输入或配置改变则重新生成。同一片段覆盖同名文件，不产生编号副本；不同时间片段保留各自输出。首次没有转换记录时重新生成一次。--force可强制重做。

## 通用源骨架

源骨架为 `资源/通用骨架.json`：使用独立的规范化人体比例和常见MMD骨名，不读取任何人物PMX、模型骨架分析文件或模型目录。可配置骨长、髋肩位置、父链旋转所用别名、足IK弯曲提示与父级枢轴。

默认骨长单位与MMD动作位移一致：上下腿各4单位、骨盆高度9单位。足IK父级默认枢轴在对应静置脚踝下方的地面，可在leg_ik中增加left_parent_pivot/right_parent_pivot三个坐标调整。骨架配置改动会触发重新转换。

转换流程：VMD→通用三维人物FK/解析足IK→腿平面展开与目标骨长适配→投影→固定Negative两骨IK→头发裙摆与眨眼→Spine JSON。四肢固定长度、不写平移缩放，镜像规则保持现有实现。

通用源骨架并不意味着任意Spine模板：目标仍是随包模板和贴图，替换目标骨架需要单独适配。源骨架比例和模型专属约束不再来自某个PMX，动作细节会与以前的模型专用结果不同，需重新视觉检查。

## 已知边界

- 转身镜像时左右肢体可能像在对调，该问题已记录并按要求暂缓；后续只在独立测试版处理。
- 通用骨架不模拟模型专属追加/扭转约束、完整MMD CCD、物理或蒙皮。
- 没有脚底锁定、独立脚尖朝向及完整手指/表情映射；眨眼为附加功能。
- 动态遮挡默认关闭，可用--draw-order试用现有实现。

本仓库附带 `极乐净土动作数据.vmd` 用于测试，也可自行添加其他VMD。不包含原模型文件/目录、PMX分析资料、历史输出或转换缓存。随包Spine模板和贴图不因此获得额外商业授权。
