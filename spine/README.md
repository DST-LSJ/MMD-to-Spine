# Spine测试目录

- `极乐净土.spine`：现有测试工程，使用Spine 4.3打开。
- `128531.atlas`、`128531.png`：现有图集资源。
- `Texture2D/`：测试工程的分图资源，保持原目录位置。

这些文件纳入版本控制；不要用忽略全部JSON或全部二进制文件的规则排除必要资源。根目录.gitignore只忽略转换器生成的*_spine.json及其他本地VMD等临时输入输出；随附测试动作 `../MMD转Spine/极乐净土动作数据.vmd` 纳入Git，可用于重新生成测试JSON。

本轮Git整理未打开或重存Spine工程，没有改变骨架、图片或动画。换电脑后如果工程提示缺图，在Spine中核对工程图片路径是否指向本目录Texture2D。
